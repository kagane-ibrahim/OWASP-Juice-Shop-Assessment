# AWS Academy Lab

## Présentation

Travail pratique académique autour d’une architecture cloud AWS comprenant des instances EC2, un répartiteur de charge, un groupe Auto Scaling, une base RDS, un bastion et des groupes de sécurité.

## Technologies et composants

Amazon EC2, Load Balancer, Auto Scaling Group, Amazon RDS, Bastion Host et Security Groups.
